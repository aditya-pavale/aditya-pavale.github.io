Why repeat AI answer checks on two different days

Repeat every AI answer check on at least two different calendar days, because the same question can return different tools, wording and sources each time. A single run can overstate or understate how visible a brand is.

What to compare

Compare the set of tools named on day one with the set named on day two. A simple overlap score (shared names divided by all names) shows how stable the answers are.

What to store

Keep each run as its own row with its date, so the two days can be compared and neither overwrites the other.
