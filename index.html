AI visibility checking method

A visibility ledger is a table with one row per real question, assistant, date, location and run, plus the raw answer, so any score can be re-checked later. This guide explains how to build one in four steps and what to avoid.

The four steps

  1. Collect real questions from recorded sources (search suggestions, 'People also ask', forums).
  2. Run each question on Google and on each AI assistant, and store the raw answer with the date and location.
  3. Score each answer as Cited, Mentioned or Not mentioned using fixed rules.
  4. Repeat on a different day, because AI answers vary.
