How to measure AI visibility for a brand

To measure AI visibility, run the same list of real questions on Google and on each AI assistant, store every raw answer with its date and location, and score each one with fixed rules. Then repeat the run on a different day, because assistant answers change.

Step 1: use real questions

Take questions from recorded sources such as search suggestions, 'People also ask' boxes and forum threads. Keep the source URL for each question. An invented list is not evidence.

Step 2: store raw answers

Save the full answer, the sources the assistant showed, the date, the assistant name and the location setting. Keep one row per question, assistant, day and run number, so a re-run never creates duplicates.

Step 3: score with fixed rules

Use the same definitions every time. See mentioned versus cited.

What to avoid

  • Typing totals by hand instead of recomputing them from the raw files.
  • Mixing methods in one column (for example an API answer and a browser answer) without a label.
  • Reporting a result you could not reproduce.
