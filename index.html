AI visibility checking method

A visibility ledger is a table with one row per real question, assistant, date, location and run, plus the raw answer, so any score can be re-checked later. This guide explains how to build one in four steps and what to avoid.

By Aditya Pavale · Published 21 November 2026 · Updated 22 November 2026

The four steps

  1. Real questions

    Collect real questions from recorded sources (search suggestions, 'People also ask', forums).

  2. Raw answers

    Run each question on Google and on each AI assistant, and store the raw answer with the date and location.

  3. Fixed scoring

    Score each answer as Cited, Mentioned or Not mentioned using fixed rules.

  4. Repeat

    Repeat on a different day, because AI answers vary.
