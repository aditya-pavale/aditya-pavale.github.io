Mentioned versus cited in AI answers

Cited means the brand's own web address is among the sources an AI assistant shows, and mentioned means the brand's name appears in the answer text without that source. If neither happens, score the answer as not mentioned.

ScoreRule
CitedThe brand's domain appears in the sources list.
MentionedThe brand name appears in the answer text, but its domain is not a source.
Not mentionedNeither appears.

Limits to record

Some assistants and some access methods return no source links, so Cited cannot be detected there. Record that limit next to the numbers instead of hiding it. Short brand names that are also ordinary words need a case-sensitive or context check to avoid false matches.
